# 经济与易用性优化待办

最后审查：2026-09-09

本文档记录本轮未实施或明确暂缓的优化项。完成、取消或调整优先级时，请同时更新“状态”“验收标准”和最后审查日期。

## 状态说明

- `待评估`：需要数据或产品决策后再排期。
- `暂缓`：当前明确不实施。
- `待实施`：方向明确，但不属于本轮范围。

## 待办清单

### E-01 图片翻译术语成本优化

- 状态：暂缓
- 原因：图片翻译功能尚未上线，当前没有真实用量数据。
- 启动条件：图片翻译进入试用或生产环境，并累计足够的请求/token 数据。
- 后续方案：统计图片请求输入 Token 占比，再决定是否区分高频术语、限制注入数量或增加检索。
- 验收标准：在不降低专有名词准确率的前提下，图片请求平均输入 Token 明显下降。

### E-02 超长文本手动分段

- 状态：待评估
- 原因：自动分段会增加模型调用次数，也可能破坏上下文和说话者对应关系。
- 建议交互：超出 3000 字时展示总字数和预计段数，由用户确认后按段落拆分。
- 验收标准：保留换行、Emoji 和段落顺序；明确展示将产生的请求数；失败段可以单独重试。

### E-03 术语 CSV 批量导入

- 状态：待实施
- 建议命令：`glossary import <file.csv> --dry-run` 和正式导入模式。
- 必需能力：UTF-8/BOM 兼容、字段校验、重复检测、新增/更新/跳过统计、事务回滚。
- 验收标准：先预览再导入；错误行有行号；任何失败不会留下半完成数据。

### E-04 用量事件保留与日汇总

- 状态：待评估
- 原因：当前数据量较小，立即增加归档逻辑收益有限。
- 启动条件：SQLite 文件或 `usage_events` 增长达到需要维护的规模。
- 后续方案：保留 90～180 天明细，更早记录按日聚合请求数、Token、计费单位和缓存命中数。
- 验收标准：额度余额不受归档影响；汇总前后累计费用一致；归档任务可重复执行。

### E-05 APK 发布产物清理

- 状态：待实施
- 当前情况：`dist/` 中存在多个历史 APK，本地约占 459 MB，目录已被 Git 忽略。
- 后续方案：工作区只保留最新正式版和上一个可回退版本，其余移动到发布页或归档存储。
- 验收标准：清理脚本默认仅预览；不会删除最新版本；归档位置和恢复方式有文档。

### S-01 HTTPS 或私有网络迁移

- 状态：待实施
- 原因：当前公网 HTTP 会明文传输访问令牌、原文和译文。
- 后续方案：优先使用 HTTPS 域名；替代方案为 Tailscale/VPN 并关闭公网端口。
- 验收标准：客户端只使用加密地址；公网明文端口关闭；旧令牌根据暴露情况完成轮换。

### M-01 Android 构建链迁移

- 状态：待评估
- 当前情况：调试编译可以通过，但 Gradle 已提示旧 Kotlin 插件用法和部分 Android 配置将在后续版本移除。
- 启动条件：准备升级 Flutter、Android Gradle Plugin 或相关插件前。
- 后续方案：先升级依赖并验证兼容性，再迁移到 Android 内置 Kotlin；不要与业务功能改动放在同一次发布中。
- 验收标准：Android 调试与正式构建通过；Flutter 分析和测试通过；不再出现对应弃用警告。

## 已完成但需要观察

### O-01 文本短时缓存与重复请求合并

- 当前配置：默认 TTL 600 秒，进程内最多 256 条，按令牌隔离。
- 观察指标：`GET /v1/usage` 和 `GET /v1/token/usage` 中的 `cache_hits`、`cache_hit_rate`。
- 复审条件：至少累计一周正常使用数据。
- 决策建议：命中率长期很低则关闭或缩短缓存；命中率高且内存稳定则保留。

- 维护要求：不得直接编辑带 `generated` 名称的文件；提交前运行各组件检查。
