# ForTranslation翻译 Android 操作手册

## 一、安装

1. 将 `ForTranslation-android-0.2.1.apk` 下载或发送到 Android 手机。
2. 点击 APK 文件安装。
3. 如果系统提示禁止安装，请按照提示允许当前文件管理器或浏览器“安装未知应用”。
4. 安装完成后打开“ForTranslation翻译”。

更新版本时，直接安装新版 APK 覆盖旧版即可。通常不会清除已保存的设置。

## 二、配置

打开 App，点击右上角“设置”。连接方式任选一种。

### 方式一：服务令牌

适合已经获得 ForTranslation 访问令牌的用户。

1. 选择“服务令牌”。
2. 填写管理员提供的独立访问令牌。
3. 点击“测试连接”。
4. 显示“连接成功”后点击“保存”。

服务地址已经内置，无需填写。

### 方式二：自有 API

适合没有服务令牌、希望使用自己大模型账号的用户。

1. 选择“自有 API”。
2. 填写 OpenAI 兼容 API 地址。
3. 填写模型名称。
4. 填写 API Key。
5. 点击“测试连接”，成功后保存。

自有 API 模式使用 App 内置术语库。API Key 仅保存在当前手机中。

### 其他设置

- “中文译文字号”：调整译文显示大小。
- “快速翻译悬浮条”：在其他 App 上方显示翻译小窗；首次启用需要授予“显示在其他应用上层”权限。
- “粘贴后自动翻译”：在悬浮窗点击“粘贴”后立即翻译。

## 三、使用

### App 内翻译

1. 在“原文”框输入文字，或点击“粘贴”。
2. 点击“翻译”。
3. 在“中文”区域查看结果。
4. 点击复制图标复制译文。
5. 需要时展开“解释”“不确定项”或“实体”查看补充信息。

单次最多输入 3000 个字符，输入框会显示实时字数。缓存命中的译文不会再次调用模型或重复计算 Token 费用。

### 悬浮窗翻译

1. 在设置中启用“快速翻译悬浮条”。
2. 在其他 App 中复制需要翻译的文字。
3. 点击屏幕上的“翻译小窗”将其展开。
4. 点击“粘贴”，再点击“翻译”。如果开启了自动翻译，粘贴后会直接翻译。
5. 译文会显示在悬浮窗中。

悬浮窗还支持：

- 拖动标题区域调整位置。
- 点击收起按钮缩成小条。
- 点击“打开 App”进入完整界面。
- 点击关闭按钮退出悬浮窗；需要时可回到设置重新启用。

## 常见问题

- 提示令牌无效或已停用：在设置中更新令牌，或联系管理员重新获取。
- 提示额度已用完：联系管理员为当前令牌充值。
- 提示内容超长：将原文缩短到 3000 个字符以内并分段翻译。
- 提示模型服务暂时不可用：稍后重试；持续出现时联系管理员检查后端模型配置。
- 提示无法连接：检查手机网络，然后重新测试连接。
- 悬浮窗不显示：检查系统设置中是否允许本应用显示在其他应用上层。
- 自有 API 翻译失败：检查 API 地址、模型名称、API Key 和账号余额。
